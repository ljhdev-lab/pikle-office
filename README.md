# 별이 비서실 🏢

아이폰 홈 화면에 추가해서 쓰는, 나만의 작은 오피스 대시보드.

- 빌드 도구 없이 동작하는 순수 HTML / CSS / JS 정적 사이트
- 폰트·스크립트·분석 도구 같은 바깥 요청은 없습니다. 날씨만 Open-Meteo(무인증)에서 30분 캐시로 받아오고, 실패하면 마지막 값이나 맑음으로 표시합니다
- 기록은 브라우저 `localStorage`(`byeol-office-v2`)에만 저장됩니다
- 오피스맵은 **캐릭터가 없는 빈 사무실 이미지 + HTML/SVG 도트 스프라이트 4명 + 시간대·날씨 레이어** 구조입니다 (이미지 안에는 글자가 없습니다)
  - 캐릭터는 자리에서 타자 치기·숨쉬기·걷기·이모지 반응을 하고, 평소에는 한 번에 한 명만 움직입니다
  - **자리에서 일할 때**: 0.26초 리듬의 몸통 지터 + 키보드 불빛 점멸 + 모니터 빛 + 손끝 점으로 '타자 치는 중'이 한눈에 보입니다
  - **회의실 모임**: 할 일이나 안건을 추가하거나 오피스맵 왼쪽 위 `회의 소집`을 누르면 넷이 각자 책상 앞에서 유리 회의실 좌석까지 경유점을 따라 걸어가 마주 앉고, 끄덕임·이모지·한마디씩 주고받으며 회의합니다. 40초쯤 뒤 또는 `회의 중 · 해산`을 누르면 각자 자리로 걸어 돌아가 타자를 칩니다
  - 경유점은 `app.js` 의 `ROOM.route`(책상 앞 → 회의실 입구)와 `ROOM.seats`(좌석 4곳)에 % 좌표로 들어 있어, 가구와 유리벽을 뚫지 않고 통로로만 걷습니다
  - 말풍선은 **네 사람이 각자 머리 위에 하나씩, 동시에 4개가 떠 있습니다**(휴식 중인 캐릭터만 숨김, 모션 OFF면 전부 숨김). 캐릭터마다 교체 박자가 달라(4.6~6.9초) 4개가 한꺼번에 바뀌지 않고, 자기 **상태 문구**와 **감정 대사**(한숨·집중·의욕·뿌듯·피곤·커피수혈 등)를 번갈아 띄웁니다. 감정은 12가지로 나뉘고 각각 작은 아이콘과 파스텔 톤·모서리가 달라 한눈에 구분됩니다
  - **회의실에 앉으면** 좌석 간격이 좁아 머리 위에 그대로 두면 겹치므로, 말풍선 네 개가 회의실 위(별이·클로드)와 아래(GPT·제미나이)로 갈라 서고 꼬리는 각자 머리를 가리킵니다. 회의 중에는 3.2~5.3초 박자로 저마다 다른 대사를 띄웁니다(`PARTS[].meet` 좌표)
  - 감정 대사는 지금 모션 상태(걷기·타이핑), 시간대(아침·낮·노을·밤), 날씨(비·눈), 남은 일감에 맞춰 골라집니다(밤엔 피곤·커피, 비엔 한숨 쪽이 더 자주). 일을 하나 끝내면 그 담당이 뿌듯한 대사를 띄웁니다
  - 네 사람의 성격 한 줄 소개는 **캐릭터 상세 패널**과 **비서현황** 탭에서 볼 수 있습니다
  - 창문 유리는 이미지에서 투명하게 뚫려 있어 뒤에 깔린 하늘 레이어(아침·낮·노을·밤, 해·달)가 비칩니다
  - 비·눈은 창문 뒤 캔버스에서 내리므로 유리창 안에서만 보입니다
  - 오른쪽 아래 칩에는 **요일·시각·날씨·기온**(예: ☀ 토 13:38 · 맑음 7°)이 30초마다 갱신됩니다. 누르면 시간대·날씨 미리보기 패널이 열리고, 미리보기 중에는 `미리보기 토 22:30 · 맑음 7°`처럼 표시됩니다
  - **파티 도트 바 (토큰 체력)**: 오피스 맵 위에 4인 상태창이 있습니다. 칸마다 도트 아이콘·이름·상태점(가동 중 · 타자 중 · 이동 중 · 회의 중 · 휴식)과 남은 일감 수, 그리고 **각 AI의 토큰(사용 한도) 잔여 체력바**가 있습니다. 클로드는 실계정 주간 잔여 %(예: `Pro 97%`), 정량 %를 주지 않는 무료 플랜(ChatGPT·제미나이·별이)은 `무료 · 여유/보통/부족` 상태로 표시합니다. 게이지는 여유일 때 담당색, 30% 이하는 주황, 15% 이하는 빨강입니다. 할 일 추가·완료·가동 토글·회의 소집은 모두 즉시 반영되고, 칸을 누르면 그 비서의 방이 열립니다. 스타일은 `style.css` 의 `.party` / `.pm`, 그리는 코드는 `app.js` 의 `renderParty()` 에 있습니다
  - **토큰 한도 맞추기**: 방 시트와 비서현황에 같은 토큰 패널이 있어, %를 주는 계정은 슬라이더로 주간 잔여 %를, 무료 플랜은 여유·보통·부족 버튼으로 상태를 직접 맞춥니다. 기본값은 실제 확인값(`QUOTA_DEFAULTS`, 클로드 Pro 주간 잔여 97%)이고, 시트에는 확인 시각과 초기화 일시가 함께 남습니다
  - **클로드 부스터 모드**: 상위 모델 Opus로 고난도 분석·작성을 맡길 때 켜는 스위치입니다. 클로드 방 시트의 `⚡ 부스터 모드` 토글이나 비서현황의 `⚡ 부스터` 칩으로 켜고 끄고, 켜져 있으면 파티 칸이 금빛 배경·금빛 게이지·`⚡ 부스터` 배지로 표시됩니다. 대화에서도 이 상태를 '부스터 모드'라고 부릅니다
  - 밤에는 실내가 어두워지고 모니터·스탠드 불빛이 켜집니다. 오른쪽 아래 칩에서 시간대·날씨를 미리보기로 바꿔 볼 수 있습니다
  - **사용 가이드**: 헤더 오른쪽 날짜 옆 `?` 를 누르면 지금 보고 있는 탭의 쓰는 법이 바텀 시트로 열립니다(핵심 한 줄 · 이렇게 써요 3단계 · 추천 루틴 · 참고 한 줄). 시트 위쪽 칩으로 다른 탭 가이드만 바꿔 볼 수 있고, X·배경 탭·Esc 로 닫힙니다. 평소엔 `?` 원 하나만 있고, 첫 방문에만 점이 하나 붙습니다. 문구는 `app.js` 의 `GUIDE`, 스타일은 `style.css` 의 `.guide-*` 에 있습니다

## 네 사람

| 자리 | 이름 | 역할 | 색·심볼 |
| --- | --- | --- | --- |
| 총괄 지휘실 | 별이 | 비서실장 · 총괄 지휘 | 소프트 블루 · 'ㅂ' 피클 몸체 |
| 콘텐츠·기획실 | GPT | 콘텐츠 · 기획 | 에메랄드 그린 · OpenAI Blossom(6갈래 꽃매듭) |
| 조사·분석실 | 클로드 | 조사 · 분석 · 문서 | 테라코타 코랄 · Claw'd(블록 몸통·네 다리) |
| 디자인·검수실 | 제미나이 | 디자인 · 검수 · 이미지 | 구글 4색 · Gemini 4각 반짝이 |

성격·감정 대사는 각 AI가 직접 정한 것을 옮겼습니다(GPT·클로드·제미나이 각 9~10개). 대사는 `app.js` 의 `PARTS[].moods`, 성격 한 줄은 `PARTS[].persona` 에서 고치면 됩니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조와 PWA 메타 태그 |
| `style.css` | 크림 톤 UI, 오피스맵 오버레이·말풍선 |
| `app.js` | 상태 저장, 오피스맵 오버레이 좌표, 체크리스트·메모·백업 |
| `assets/office-map-v5.webp` | 캐릭터 없는 코지 픽셀아트 아이소메트릭 비서실 — 가운데 유리 파티션 회의실(테이블·의자 4석·화이트보드·발표 화면) (864×1152, 창문 유리 알파) |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 앱 아이콘 |
| `manifest.json` | 웹 앱 매니페스트 |
| `tools/` | 아이콘·장면 미리보기용 개발 스크립트 (배포에는 필요 없음) |

### 오피스맵 좌표 고치기

`app.js` 위쪽 `PARTS` 의 `home`(발바닥 중앙) · `tag`(이름표) · `bubble`(말풍선) 값이 이미지 안의 % 위치입니다.
회의실 좌석과 이동 경유점은 바로 아래 `ROOM.seats` · `ROOM.route` 에 있습니다.
이미지를 새로 뽑으면 그 값만 다시 맞추면 됩니다.

# 별이 비서실 · 모니터링 📊

아이폰 홈 화면에 추가해서 쓰는 **채팅 작업 모니터링 현황판**.

- 빌드 도구 없이 동작하는 순수 HTML / CSS / JS 정적 사이트
- **보기 전용**입니다. 할 일·안건·상태를 여기서 추가·수정·삭제하지 않습니다. 실제 작업 지시는 피클 채팅에서 하고, 이 화면에서는 진행 상태·한도·모임만 확인합니다
- 값은 `data/office-state.json` 한 곳에서 내려옵니다. 앱은 열 때와 `새로고침`을 누를 때 이 파일을 새로 읽습니다
- 폰트·스크립트·분석 도구 같은 바깥 요청은 없습니다. 날씨만 Open-Meteo(무인증)에서 30분 캐시로 받아오고, 실패하면 마지막 값이나 맑음으로 표시합니다
- 브라우저 `localStorage`(`byeol-office-v2`)에는 **화면 설정만** 저장합니다(모션 ON/OFF, 마지막 탭, 시간·날씨 미리보기, 담당 필터). 일·안건·한도의 정본은 JSON 파일입니다
- 오피스맵은 **캐릭터가 없는 빈 사무실 이미지 + HTML/SVG 도트 스프라이트 4명 + 시간대·날씨 레이어** 구조입니다 (이미지 안에는 글자가 없습니다)

## 무엇을 보여 주나

| 탭 | 보여 주는 것 |
| --- | --- |
| **오피스 맵** | 오늘의 브리핑 요약(읽기 전용), 4인 파티 도트 바(상태·남은 일감·토큰 잔여·부스터), 캐릭터 모션, 시간·날씨, 회의 소집 연출 |
| **회의실** | 채팅에서 오간 주요 안건의 진행 상태(결정 대기·정리됨)와 날짜 |
| **작업실** | 채팅에서 맡긴 일을 **현재 / 예약(단발·정기) / 완료** 구역으로 나눠 표시. 담당·예정 시각, 동기화 시각, 담당별 필터, 예약 제외 진행률 |
| **비서현황** | 네 사람의 현재 상태(가동·타자·회의·휴식), 역할·성격, 남은 일감, 토큰 잔여, 회복 시각 |
| **동기화·안내** | 마지막 동기화 시각, 받은 작업·안건 수, 새로고침, AI별 한도 회복 주기, 모니터링 사용법 |

모든 탭에 입력 폼·완료 체크박스·삭제 버튼이 없습니다. 누를 수 있는 것은 탭 이동, 캐릭터·파티 칸 열기, 새로고침, 담당 필터, 그리고 화면 연출(모션·회의 소집·시간 날씨)뿐입니다.

## 오피스 맵 연출

- 캐릭터는 자리에서 타자 치기·숨쉬기·걷기·이모지 반응을 하고, 평소에는 한 번에 한 명만 움직입니다
- **자리에서 일할 때**: 0.26초 리듬의 몸통 지터 + 키보드 불빛 점멸 + 모니터 빛 + 손끝 점으로 '타자 치는 중'이 한눈에 보입니다
- **회의실 모임**: 오피스맵 왼쪽 위 `회의 소집`을 누르면 넷이 각자 책상 앞에서 유리 회의실 좌석까지 경유점을 따라 걸어가 마주 앉고, 끄덕임·이모지·한마디씩 주고받으며 회의합니다. 40초쯤 뒤 또는 `회의 중 · 해산`을 누르면 각자 자리로 걸어 돌아갑니다
- 경유점은 `app.js` 의 `ROOM.route`(책상 앞 → 회의실 입구)와 `ROOM.seats`(좌석 4곳)에 % 좌표로 들어 있어, 가구와 유리벽을 뚫지 않고 통로로만 걷습니다
- 말풍선은 **네 사람이 각자 머리 위에 하나씩, 동시에 4개가 떠 있습니다**(휴식 중인 캐릭터만 숨김, 모션 OFF면 전부 숨김). 자기 **상태 문구**와 **감정 대사**를 번갈아 띄웁니다
- 감정 대사는 지금 모션 상태(걷기·타이핑), 시간대(아침·낮·노을·밤), 날씨(비·눈), 남은 일감에 맞춰 골라집니다
- 창문 유리는 이미지에서 투명하게 뚫려 있어 뒤에 깔린 하늘 레이어가 비치고, 비·눈은 창문 뒤 캔버스에서 내립니다
- 오른쪽 아래 칩에는 **요일·시각·날씨·기온**이 30초마다 갱신됩니다. 누르면 시간대·날씨 미리보기 패널이 열립니다
- **파티 도트 바 (토큰 체력)**: 칸마다 도트 아이콘·이름·상태점(가동 중 · 타자 중 · 이동 중 · 회의 중 · 휴식)과 남은 일감 수, 그리고 **각 AI의 토큰(사용 한도) 잔여 체력바**가 있습니다. 클로드는 실계정 주간 잔여 %(예: `Pro 97%`), 정량 %를 주지 않는 무료 플랜은 `무료 ~17%`처럼 추정치로 표시합니다. 30% 이하는 주황, 15% 이하는 빨강입니다
- **부스터 모드**: 클로드가 Opus로 고난도 작업을 하는 중이면 파티 칸과 방 시트에 `⚡ 부스터` 배지가 붙습니다. 켜고 끄는 건 채팅에서 "부스터 모드로 해줘"처럼 말하면 됩니다
- 밤에는 실내가 어두워지고 모니터·스탠드 불빛이 켜집니다

## 채팅 작업 동기화

채팅에서 맡긴 일·안건·브리핑·토큰 값은 `data/office-state.json` 에 적힙니다.

```json
{
  "updatedAt": "2026-11-28T16:55:00+09:00",
  "brief": "오늘의 브리핑 한 줄",
  "boost": { "claude": false },
  "tokens": { "claude": { "pct": 97, "basis": "measured", "asOf": "2026-11-28T15:00:00+09:00" } },
  "agenda": [{ "id": "chat-1128-agenda-blog", "title": "이번 주 블로그 주제 선정", "done": false, "date": "11.28" }],
  "tasks": [{ "id": "chat-1129-comments", "title": "블로그 새 글·댓글 정기 점검", "owner": "gpt", "done": false, "date": "11.29", "runAt": "2026-11-29T11:48:00+09:00", "every": "매주", "source": "chat" }]
}
```

- 파일은 `./data/office-state.json?t=시각` 으로 매번 새로 읽습니다. 없거나 네트워크가 막히면 앱은 마지막으로 받은 값으로 그대로 동작합니다
- `tasks` 는 `source: "chat"` 인 항목만 받고, 같은 `id` 는 완료 쪽으로만 맞춥니다
- `runAt` 은 예약 시각(`+09:00` ISO 8601), `every` 는 반복 주기(예: `매주`, `매월 1일`)입니다. 앱이 `done`·`runAt`·`every` 로 **현재 / 예약(단발·정기) / 완료** 구역을 계산합니다
  - `done: true` → 완료, `every` 있음 → 정기, `runAt` 이 미래 → 단발, `runAt` 이 지났는데 미완료 → 확인 필요, 나머지 → 진행 중
  - 정기 일감은 한 번 끝내도 `done` 대신 `runAt` 을 다음 회차로 갱신합니다
- `agenda` 는 파일에 적힌 목록으로 통째로 바뀝니다(진행 상태·날짜 포함)
- `brief` 는 오피스 맵 상단의 오늘의 브리핑 요약으로 표시됩니다
- `tokens` 는 AI별 잔여 한도입니다. `basis: "measured"` 는 실제 화면에서 확인한 값, `"estimate"` 는 작업 수로 어림한 추정치(`~17%` 표시)입니다
- `boost` 는 부스터 모드 표시(현재 클로드만)입니다
- 예전 버전이 넣어 둔 예시 할 일(`t1`~`t5`)은 동기화할 때 한 번 걷어 냅니다

> 이 저장소는 공개입니다. `data/office-state.json` 에는 **실명·회사명·주소·전화번호·이메일·계정·사적인 기록을 넣지 않고**, 누구의 일인지 알 수 없는 일반 작업명만 적습니다.

## 토큰 체력 (잔여 한도)

- 측정값이 있는 곳(클로드 Pro)은 실제 화면에서 확인한 %, 그 밖에는 시킨 작업 수로 어림한 추정치(`~17%`)로 표시합니다. 추정치에는 방 시트·비서현황에 `추정` 이라고 적힙니다
- 회복 시각이 지나면 앱이 100%로 되돌립니다. 앱을 열어 둔 상태에서도 1분마다 확인합니다

| 자리 | 회복 시각 | 한 건당 표시 |
| --- | --- | --- |
| 별이 (무료) | 매일 04:00 | -8% 추정 |
| GPT (무료) | 마지막 사용 5시간 뒤 | -10% 추정 |
| 클로드 (Pro) | 매주 토 05:00 | -4% (-8% 부스터) |
| 제미나이 (무료) | 매일 00:00 | -8% 추정 |

기준값과 회복 규칙은 `app.js` 의 `QUOTA_DEFAULTS` · `QUOTA_RESET` · `QUOTA_RECOVER` 에 모여 있고, 실제 값은 `data/office-state.json` 의 `tokens` 로 내려옵니다.

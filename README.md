# 별이 비서실 🏢

아이폰 홈 화면에 추가해서 쓰는, 나만의 작은 오피스 대시보드.

- 빌드 도구 없이 동작하는 순수 HTML / CSS / JS 정적 사이트
- 폰트·스크립트·분석 도구 같은 바깥 요청은 없습니다. 날씨만 Open-Meteo(무인증)에서 30분 캐시로 받아오고, 실패하면 마지막 값이나 맑음으로 표시합니다
- 기록은 브라우저 `localStorage`(`byeol-office-v2`)에만 저장됩니다
- 오피스맵은 **캐릭터가 없는 빈 사무실 이미지 + HTML/SVG 도트 스프라이트 4명 + 시간대·날씨 레이어** 구조입니다 (이미지 안에는 글자가 없습니다)
  - 캐릭터는 자리에서 숨쉬기·타이핑·걷기·이모지 반응을 하고, 한 번에 한 명만 움직입니다
  - 말풍선은 그 비서의 **상태 문구**와 **감정 대사**(한숨·집중·의욕·뿌듯·피곤·커피수혈 등)를 번갈아 띄웁니다. 감정은 12가지로 나뉘고 각각 작은 아이콘과 파스텔 톤·모서리가 달라 한눈에 구분됩니다
  - 감정 대사는 지금 모션 상태(걷기·타이핑), 시간대(아침·낮·노을·밤), 날씨(비·눈), 남은 일감에 맞춰 골라집니다(밤엔 피곤·커피, 비엔 한숨 쪽이 더 자주). 일을 하나 끝내면 그 담당이 뿌듯한 대사를 띄웁니다
  - 네 사람의 성격 한 줄 소개는 **캐릭터 상세 패널**과 **비서현황** 탭에서 볼 수 있습니다
  - 창문 유리는 이미지에서 투명하게 뚫려 있어 뒤에 깔린 하늘 레이어(아침·낮·노을·밤, 해·달)가 비칩니다
  - 비·눈은 창문 뒤 캔버스에서 내리므로 유리창 안에서만 보입니다
  - 밤에는 실내가 어두워지고 모니터·스탠드 불빛이 켜집니다. 오른쪽 아래 칩에서 시간대·날씨를 미리보기로 바꿔 볼 수 있습니다

## 네 사람

| 자리 | 이름 | 역할 | 색·심볼 |
| --- | --- | --- | --- |
| 총괄 지휘실 | 별이 | 비서실장 · 총괄 지휘 | 소프트 블루 · 'ㅂ' 피클 몸체 |
| 콘텐츠·기획실 | GPT | 콘텐츠 · 기획 | 에메랄드 그린 · OpenAI Blossom(6갈래 꽃매듭) |
| 조사·분석실 | 클로드 | 조사 · 분석 · 문서 | 테라코타 코랄 · Claw'd(블록 몸통·네 다리) |
| 디자인·검수실 | 제미나이 | 디자인 · 검수 · 이미지 | 구글 4색 · Gemini 4각 반짝이 |

성격·감정 대사는 각 AI가 직접 정한 것을 옮겼습니다(GPT·클로드·제미나이 각 9~10개). 대사는 `app.js` 의 `PARTS[].moods`, 성격 한 줄은 `PARTS[].persona` 에서 고치면 됩니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조와 PWA 메타 태그 |
| `style.css` | 크림 톤 UI, 오피스맵 오버레이·말풍선 |
| `app.js` | 상태 저장, 오피스맵 오버레이 좌표, 체크리스트·메모·백업 |
| `assets/office-map-v4.webp` | 캐릭터 없는 코지 픽셀아트 아이소메트릭 비서실 (864×1152, 창문 유리 알파) |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 앱 아이콘 |
| `manifest.json` | 웹 앱 매니페스트 |
| `tools/` | 아이콘·장면 미리보기용 개발 스크립트 (배포에는 필요 없음) |

### 오피스맵 좌표 고치기

`app.js` 위쪽 `PARTS` 의 `home`(발바닥 중앙) · `tag`(이름표) · `bubble`(말풍선) 값이 이미지 안의 % 위치입니다.
이미지를 새로 뽑으면 그 값만 다시 맞추면 됩니다.

## 데이터 옮기기

`메모·백업` 탭에서 **JSON 내보내기**로 파일을 받아 두고,
새 기기에서 **JSON 불러오기**로 그 파일을 고르면 그대로 복원됩니다.
이전 버전(`byeol-office-v1`)의 기록은 처음 열 때 자동으로 새 구조로 옮겨 옵니다.
